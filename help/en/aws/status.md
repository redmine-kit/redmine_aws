# Status

Administration › AWS › **Status** shows the versions of Redmine and of the installed Redmine Kit AWS plugins, and the names of the settings read from SSM Parameter Store (names only, never values). The Redmine Kit AWS plugins add more to this page and more tabs next to it; on AWS Lambda, for example, the page also shows the Lambda function and the Redmine settings fixed there.

**Test** checks the database and each AWS service the installed plugins use, once, and shows **OK** or **Failed** with the details and the response time. Only administrators can open the page.

More: [Redmine Kit AWS: administration pages](https://redmine-kit.github.io/redmine_aws/admin.html).
