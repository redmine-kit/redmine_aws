# ステータス

「管理」›「AWS」›「ステータス」には、Redmine とインストールした Redmine AWS のプラグインのバージョン、SSM Parameter Store から読み込んだ設定の名前 (値は表示しません) を表示します。Redmine AWS のプラグインは、このページに項目を、隣にタブを追加します。たとえば AWS Lambda では、Lambda 関数と、Lambda で固定している Redmine の設定も表示します。

「テスト」を押すと、データベースと、インストールしたプラグインが使う AWS のサービスへの接続を 1 回ずつ確認し、「OK」または「失敗」と詳細、応答時間を表示します。このページを開けるのはシステム管理者だけです。

詳しくは [Redmine AWS の管理画面](https://redmine-kit.github.io/redmine_aws/ja/admin.html) を参照してください。
